# FlyWorld Web

Jardim 3D interativo para navegador. Consulte ../docs/DEPLOY_VERCEL.md para arquitetura, dados reais, limitações e publicação.

npm ci
npm test
npm run build
npm run dev

Origem do modelo neural e da licença: https://github.com/eonsystemspbc/fly-brain. A cópia da licença está em public/LICENSE-fly-brain.txt. O simulador biológico completo continua no aplicativo Python local; a navegação web usa aprendizagem artificial e replay de dados gravados.
